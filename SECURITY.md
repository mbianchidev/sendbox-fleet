# Security

Please report suspected vulnerabilities privately to the repository owner
([@mbianchidev](https://github.com/mbianchidev)) rather than in issues or pull
requests. A dedicated reporting channel will be defined before this repository
is made public.

The security design is described in [docs/threat-model.md](docs/threat-model.md).
This service is a scaffold: it authorizes nothing yet and must not be deployed
as a governance authority.
